# IFRS Connect

IFRS Connect is a deterministic, audit‑grade IFRS 16 calculator designed for accountants, auditors, and finance teams who need mathematically defensible lease accounting without spreadsheets or hidden logic.

## What it does
- Deterministic IFRS 16 calculations  
- Transparent amortisation schedules and journals  
- Clean handling of modifications, CPI/indexation, and term changes  
- Audit‑ready outputs with no manual adjustments  
- Professional UI built for real finance teams
